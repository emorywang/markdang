# 架构说明

[English](architecture.md) · [README](../README.zh-CN.md)

MarkDang 是 Manifest V3 扩展，运行时由四个部分组成：

| 组件 | 职责 |
| --- | --- |
| 启动脚本 | 短暂隐藏最初的纯文本视图；启动失败时恢复原始内容 |
| 内容脚本 | 解析并清理文档，渲染阅读器、大纲和目录 |
| Service Worker | 串行写入设置，处理本地文件探测，转发快捷键 |
| 设置页与弹窗 | 共享一个 Preact 设置组件，观察本地设置变更 |

## 设置

`src/shared/settings.ts` 定义默认值和公开存储键。读取时递归合并已知字段，验证类型和枚举，限制数值范围。数组采用替换而非拼接；未知字段不进入归一化设置。

应用写入经过 Service Worker 的先进先出队列。每份补丁与最新存储设置合并，只写入涉及的顶层键，避免快速操作或多个扩展页面互相覆盖无关设置。插件补丁只包含修改的字段；只观察 `local` 存储区的变化。

## 界面语言

`src/shared/i18n.ts` 提供完整且受类型检查的中英文文案对。语言设置为 `auto`、`zh-CN` 或 `en`；自动模式优先读取 `chrome.i18n.getUILanguage()`。所有中文变体使用简体中文，其他浏览器语言回退到英文。

设置页和弹窗共享翻译上下文。阅读器仅更新控件文案、大纲折叠标签和目录提示，不重新解析 Markdown，也不重建正文，因此保留阅读位置、任务勾选及大纲折叠状态。文档文字、代码、文件名不参与翻译。

扩展简介和快捷键说明通过 `public/_locales/` 使用浏览器原生本地化，英文是默认语言；两种中文区域使用相同简体文案。此类浏览器管理的说明只跟随浏览器语言。

## 本地文件

内容脚本不能直接获取 `file:` 资源。阅读器请求 Worker 在非活动标签页打开当前文件或其直接父目录。URL 含有唯一探测标记；内容脚本启动时先询问 Worker 该标签页是否确为探测页，报告原始文字或目录项，并且仅对确认的探测页跳过阅读器。

Worker 校验发送者、顶层框架、源 URL、目标 URL、探测类型和报告标签页。同一资源的并发请求共享正在进行的探测；两次轮询之间不缓存结果，以便观察后续文件修改。完成时清理定时器；超时、标签关闭或创建失败都会结束请求并清理临时标签。迟到的回调不能结束替代它的新探测。

普通非活动标签页仍正常渲染。网页自动刷新和目录读取使用同源请求；目录解析以请求 URL 为基准解析链接，只接受同源的直接子项。

## 渲染与安全

每次按当前插件设置创建新的 markdown-it 渲染器，处理元数据、标题与目录、公式、表格、警告框及图表占位。生成 TOC 前分配标题 ID，包括未进入 TOC 的标题；重复标题及本身带数字后缀的标题仍具有唯一 ID。目录形成有效的嵌套树，不生成空中间层。

文档 HTML 插入页面前经过 DOMPurify 清理，移除可执行标记、表单、活动嵌入、样式表及危险 URL。元数据和生成的属性值会转义；任务复选框仍受支持。清理后的 HTML 重新解析为新节点，避免把解析器缓存的事件处理器跨扩展隔离边界带入页面。原始源码独立保存。

Mermaid 在需要时从扩展包延迟加载。渲染串行执行，并用版本号阻止旧异步结果替换新内容。不论用户 JSON 或文档指令如何设置，安全模式固定为 `strict`；生成的 SVG 也会清理。脚本回调和 HTML 标签不可用。无效图表保留源码并显示文本错误。

PlantUML 是独立网络功能，不参与本地插件总开关。完整网络行为见[隐私声明](../PRIVACY.zh-CN.md)。

## 阅读器生命周期

根据 MIME 类型和受支持的 URL 扩展名判断是否渲染。页面最初的 `<pre>` 是原始源码；渲染出的代码块不作为文档来源。切换总开关、`.txt` 或目录功能会重载当前页面，恢复浏览器原始 DOM 或重新启动阅读器。符合条件的页面即使关闭渲染，也保留设置观察者。

每个阅读器只有一个刷新定时器和一个进行中的轮询。请求设有超时，并且只接收文本文档响应。系统配色变更会即时更新自动主题。大纲折叠与正文渲染独立，搜索可显示折叠区域内的匹配项。

## 构建

五次顺序 Vite 构建分别生成设置/弹窗的 ES 模块，以及内容脚本、经典 Worker、启动脚本、Mermaid 的单文件 IIFE。经典 Worker 保持构建简单；内容脚本仍可动态加载打包且公开可访问的模块。

构建清理旧输出，检查包与 manifest 版本，转义原始 U+FFFE/U+FFFF 字符，并附带项目和第三方许可声明。KaTeX 样式随阅读器打包，公式字体使用按需加载的本地 WOFF2 文件；字体与 Mermaid 是扩展公开资源。不会从 CDN 下载执行代码。
